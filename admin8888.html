Login Admin

Masuk pakai akun admin yang kamu buat di Firebase Authentication.

Kalau login gagal, aktifkan dulu Email/Password di Firebase Authentication dan tambahkan user admin. Email terakhir yang dipakai akan disimpan lokal di browser admin.

Verifikasi A2F

Login Firebase berhasil. Masukkan kode A2F tahap 1 dari 3 untuk membuka dashboard.

1 2 3
Role admin sudah dicek. Dashboard masih terkunci sampai A2F selesai.
A2F ini memakai SHA-256 hash di dalam file. Untuk mengganti kode, ubah nilai TWO_FACTOR_HASHES di script.
