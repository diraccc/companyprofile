Karena kamu hosting frontend di GitHub Pages, backend tetap berada di hosting/API kamu. GitHub hanya menampilkan tampilan depan.

1

User Pilih Produk

User memilih kategori game, e-wallet, e-toll, pulsa, data, PLN, atau voucher.

2

Isi Data Tujuan

User mengisi ID game, nomor HP, nomor kartu, atau data lain sesuai produk.

3

Kirim ke API

Frontend mengirim data ke backend. Backend yang membuat invoice dan mengecek harga final.

4

Cek Status

User mengecek invoice. Untuk demo ini, status disimpan di browser dulu.
