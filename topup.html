PANDUAN & FAQ

Artikel Bantuan Top Up Game

Baca panduan ini sebelum membuat pesanan agar data game, nominal, pembayaran, dan pengecekan status tidak keliru.

01

Panduan Cara Order

Alur pemesanan dibuat ringkas: pilih game, isi data tujuan, pilih nominal, pilih QRIS, lalu lanjutkan pembayaran.

  • Pastikan game yang dipilih sudah sesuai.
  • Periksa User ID sebelum menekan tombol pembayaran.
  • Simpan kode invoice untuk pengecekan status.
02

Cara Mengisi ID Game dan Server

Setiap game memiliki format ID yang berbeda. Ikuti format yang diminta agar pesanan masuk ke akun yang benar.

  • Mobile Legends memakai User ID dan Server ID.
  • Free Fire umumnya memakai Player ID.
  • Game tertentu memakai UID, Riot ID, atau username.
03

Estimasi Proses Pesanan

Pesanan diproses setelah pembayaran terkonfirmasi oleh sistem. Kecepatan proses dapat berbeda mengikuti antrean dan kondisi provider game.

  • Status awal: menunggu pembayaran.
  • Status berikutnya: diproses oleh sistem.
  • Status akhir: selesai atau butuh pengecekan support.
04

Metode Pembayaran

Pembayaran menggunakan metode yang tersedia pada form order. Saat ini tampilan checkout diarahkan pada QRIS.

  • Bayar sesuai total yang muncul di ringkasan.
  • Jangan menutup halaman sebelum invoice tersimpan.
  • Gunakan satu invoice untuk satu transaksi.
05

Cara Cek Status Pesanan

Status pesanan dapat dilihat melalui kode invoice. Masukkan kode tersebut pada bagian cek status setelah pembayaran dilakukan.

  • Gunakan kode invoice yang benar.
  • Refresh riwayat bila status belum berubah.
  • Hubungi support jika status terlalu lama tertahan.
06

Kebijakan Salah Input ID

Data tujuan menjadi tanggung jawab pembeli sebelum pembayaran. Pesanan yang sudah masuk ke ID salah berisiko tidak dapat ditarik kembali.

  • Periksa angka User ID satu per satu.
  • Periksa Server ID untuk game yang membutuhkannya.
  • Jangan memakai ID akun orang lain tanpa izin.
07

Kebijakan Refund

Refund hanya dapat dipertimbangkan apabila pesanan belum berhasil diproses ke akun game dan kendala terbukti berasal dari sistem layanan.

  • Refund tidak berlaku untuk ID salah yang sudah sukses terkirim.
  • Bukti pembayaran dan invoice wajib disiapkan.
  • Keputusan akhir mengikuti hasil pengecekan support.
08

Keamanan Data Pengguna

Form order hanya meminta data yang diperlukan untuk pemrosesan top up game. Jangan pernah membagikan password akun game.

  • Top up tidak membutuhkan password akun.
  • Jangan kirim OTP kepada pihak mana pun.
  • Gunakan kontak support resmi yang tersedia di website.
09

Syarat dan Ketentuan

Dengan membuat pesanan, pembeli menyetujui bahwa data tujuan sudah benar dan transaksi diproses berdasarkan pilihan pada form order.

  • Harga dan nominal mengikuti tampilan pada checkout.
  • Pesanan tidak boleh digunakan untuk aktivitas ilegal.
  • Layanan dapat tertunda jika provider game mengalami gangguan.

FAQ Top Up Game

Jawaban berikut dibuat tegas agar pembeli memahami batas layanan sebelum melakukan pembayaran.

Wajib Dibaca
Apakah layanan ini khusus top up game?

Ya. Bagian order pada website ini difokuskan untuk top up game. Pilih game yang tersedia pada form, lalu isi ID tujuan sesuai format game tersebut.

Apakah saya perlu memberikan password akun game?

Tidak. Top up game tidak membutuhkan password. Jangan memberikan password, kode OTP, kode verifikasi, atau akses login kepada siapa pun.

Bagaimana jika User ID atau Server ID salah?

Kesalahan input menjadi risiko pembeli. Jika pesanan sudah berhasil masuk ke akun yang salah, transaksi berpotensi tidak bisa dibatalkan atau direfund.

Kapan pesanan saya diproses?

Pesanan diproses setelah pembayaran terkonfirmasi. Estimasi dapat berubah karena antrean, gangguan provider game, atau pengecekan transaksi oleh sistem.

Apa yang harus dilakukan jika status pesanan belum berubah?

Cek kembali invoice, pastikan pembayaran sudah berhasil, lalu tunggu proses sinkronisasi. Jika terlalu lama, hubungi support dengan menyertakan invoice dan bukti pembayaran.

Apakah pembayaran boleh berbeda dari total invoice?

Tidak disarankan. Pembayaran harus mengikuti total pada checkout agar sistem lebih mudah mencocokkan transaksi.

Apakah refund selalu bisa dilakukan?

Tidak. Refund hanya dipertimbangkan untuk pesanan yang belum berhasil diproses dan setelah kendala diverifikasi oleh support.

Apakah harga dapat berubah?

Ya. Harga dapat berubah mengikuti stok, provider game, biaya sistem, atau kebijakan layanan. Harga yang berlaku adalah harga yang tampil saat checkout.

Apakah invoice harus disimpan?

Ya. Invoice adalah bukti awal untuk mengecek status dan memudahkan support menelusuri transaksi.

Bagaimana cara menghubungi support?

Gunakan tombol WhatsApp atau email support resmi pada bagian Support. Sertakan invoice, nama game, nominal, User ID, dan bukti pembayaran.

Catatan tegas: transaksi hanya boleh dilanjutkan setelah data game benar. Jangan membayar jika masih ragu terhadap User ID, Server ID, nominal, atau game yang dipilih.
