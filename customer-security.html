Global production hardening

Bagian ini menjelaskan prinsip keamanan halaman. Ini bukan pengganti kontrol server, tetapi membantu mencegah UI salah arah.

✅ No secret in browser

File ini tidak menyimpan service_role key, token, password, atau recovery code di client.

✅ Credentials include only

Fetch memakai cookie session server dengan credentials: include, bukan localStorage token.

✅ Safe rendering

Data backend dirender lewat textContent, bukan HTML injection.

✅ Read-only by default

Semua kontrol sensitif disabled sampai endpoint write khusus tersedia.

✅ API failure safe

Jika API error/401, halaman masuk ke mode terkunci dan tidak menampilkan data palsu.

✅ Legacy isolation

Halaman baru berdiri sendiri dan tidak mengubah dashboard admin/staff, login, hash, atau A2F lama.
